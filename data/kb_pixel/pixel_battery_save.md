# How to Save Battery on Pixel

## Overview
Extend Pixel battery life using built-in power saving features.

## When to Use
- Battery draining fast
- Need phone to last longer
- Traveling without charger

## Steps
- Enable Battery Saver: Settings → Battery → Battery Saver → Toggle on
- Enable Adaptive Battery: Settings → Battery → Adaptive preferences → Adaptive Battery
- Reduce brightness or enable Adaptive brightness
- Turn off Always-On Display: Settings → Display → Lock screen → Disable
- Enable Dark theme: Settings → Display → Dark theme
- Disable 5G: Settings → Network → SIMs → Preferred network → LTE
- Turn off Bluetooth/Wi-Fi when not needed
- Set shorter screen timeout: Settings → Display → Screen timeout → 30 seconds

## Notes
- Extreme Battery Saver can extend to 72 hours
- Adaptive Battery learns usage over 1-2 weeks
- Dark theme saves significant battery on OLED screens
