# Factory Reset Pixel

## Overview
Erase all data and restore phone to original state.

## When to Use
- Selling or giving away phone
- Persistent software issues
- Starting fresh

## Backup First
- Settings → Google → Backup → Ensure backup is on
- Sync photos to Google Photos
- Note app-specific data

## Steps
- Go to Settings → System → Reset options
- Tap Erase all data (factory reset)
- Tap Erase all data to confirm
- Enter PIN if prompted
- Wait for completion

## Reset via Recovery (if phone won't boot)
- Power off completely
- Hold Power + Volume Down until bootloader
- Navigate to Recovery mode with Volume buttons
- Press Power to select
- Select Wipe data/factory reset

## Notes
- Deletes ALL data permanently
- Cannot be undone
- Backup photos and important files first
