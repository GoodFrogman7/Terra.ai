# Circle to Search

## Overview
Search anything on screen by circling, highlighting, or tapping it.

## When to Use
- Identify objects in photos
- Search text on screen
- Find products to buy
- Identify plants, animals, landmarks

## Steps
- Long-press home button (gesture nav) or navigation bar (3-button)
- Screen shimmers when active
- Circle, highlight, or tap any element
- Search results appear instantly
- Tap outside results to return

## Notes
- Works in any app including videos
- Requires internet connection
- Can solve math equations
- Identifies songs from lyrics
- Enable: Settings → Display → Navigation mode → Circle to Search
