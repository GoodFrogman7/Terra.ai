# Fix Wi-Fi Connection Issues

## Overview
Troubleshoot Wi-Fi connectivity problems on Pixel.

## When to Use
- Wi-Fi keeps disconnecting
- Cannot connect to network
- Slow Wi-Fi speeds

## Steps
- Toggle Wi-Fi off and on
- Forget network: Settings → Network → Wi-Fi → Tap network → Forget
- Reconnect with password
- Restart phone
- Restart router/modem
- Reset network settings: Settings → System → Reset options → Reset Wi-Fi, mobile & Bluetooth

## Notes
- Check if other devices have same issue (router problem)
- Move closer to router
- Update phone software
- Factory reset as last resort
