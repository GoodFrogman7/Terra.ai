# Fingerprint Setup

## Overview
Set up fingerprint unlock for fast, secure device access.

## When to Use
- Want quick unlock without PIN
- Need biometric security
- Setting up new Pixel

## Steps
- Go to Settings → Security & privacy → Device unlock
- Tap Fingerprint Unlock
- Enter PIN/password
- Touch fingerprint sensor repeatedly until complete
- Register multiple fingers for convenience

## Tips for Better Recognition
- Register same finger twice for improved accuracy
- Ensure finger is dry and clean
- Clean sensor regularly
- Register fingers in different positions

## Notes
- Requires PIN/password as backup
- Works for unlocking and app authentication
- Under-display sensor on newer Pixels
