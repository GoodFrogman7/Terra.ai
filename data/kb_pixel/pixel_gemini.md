# Gemini AI Assistant

## Overview
Google's advanced AI assistant for complex tasks and conversations.

## When to Use
- Need help writing emails/messages
- Want to summarize articles
- Complex questions
- Creative content generation

## Access Gemini
- Long-press power button
- Say "Hey Google" (if enabled)
- Swipe up from screen corner

## Features
- Answer complex questions
- Write and edit text
- Summarize web pages
- Analyze images
- Control smart home
- Set reminders and alarms

## Gemini Live (Conversational)
- Open Gemini, tap Live button (wave icon)
- Have natural flowing conversation
- Can interrupt anytime
- Good for brainstorming

## Notes
- Requires internet connection
- Replaces Google Assistant on supported Pixels
- Switch back: Settings → Google → Digital assistant app
