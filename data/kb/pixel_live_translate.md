# Live Translate

## Overview
Real-time translation for conversations, messages, and media.

## When to Use
- Face-to-face conversations in different languages
- Receiving messages in other languages
- Watching foreign language videos

## Interpreter Mode
- Say "Hey Google, be my interpreter"
- Choose both languages
- Speak naturally, translations appear and spoken aloud
- Screen shows both languages in large text

## Message Translation
- Receive message in another language
- Tap Translate below message
- Reply in your language, auto-translates before sending

## Live Caption Translation
- Enable: Settings → Sound & vibration → Live Caption
- Audio in other languages shows captions in your language
- Works with videos, podcasts, voice messages

## Notes
- 50+ languages for text
- Offline translation packs available
- Works on-device for privacy
