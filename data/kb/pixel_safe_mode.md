# Boot into Safe Mode

## Overview
Start Pixel with only system apps to diagnose third-party app issues.

## When to Use
- Phone crashing frequently
- Suspect bad app causing problems
- Testing if issue is system or app-related

## Steps
- Press and hold Power button
- Touch and hold Power off option
- Tap OK when Safe Mode prompt appears
- Phone restarts with Safe Mode in corner
- Test if issue persists

## Exit Safe Mode
- Restart phone normally
- All third-party apps re-enabled

## Notes
- Third-party apps disabled in Safe Mode
- If issue gone in Safe Mode, a third-party app is the cause
- Uninstall recent apps one by one to find culprit
