# Find My Device - Locate Lost Pixel

## Overview
Locate, lock, or erase a lost Pixel phone remotely.

## Setup (Before Losing)
- Settings → Google → Find Hub
- Enable Allow device to be located
- Join Find network

## When Lost
- Go to android.com/find on any device
- Sign in with Google account
- Select your Pixel

## Actions
- Play Sound: Ring even if silent
- Secure Device: Lock with message
- Erase Device: Delete all data remotely

## Notes
- Phone needs internet for most features
- Some Pixels locatable when off (limited time)
- Enable before losing phone
- Works across all Android devices
